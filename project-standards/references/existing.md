# Applying Standards to an Existing Repository

Never assume an existing repository is empty.

1. Inspect the repository first.
2. Do not recreate Git.
3. Do not overwrite working configuration unnecessarily.
4. Preserve existing functionality.
5. Apply these standards incrementally.
6. Use separate commits for logically independent changes.
7. Do not introduce unnecessary migrations.
8. Identify conflicts with existing architecture.
9. Choose the smallest compatible deviation.
10. Report deviations clearly.
